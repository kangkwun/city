# 챔피언스시티 조망 비교

동·타입·층·창에 따른 예상 조망과 사계절 직사광을 비교하는 정적 웹사이트입니다.
공식 분양 서비스나 실측 VR이 아니며, 실제 조망·잔여 세대·일조·가격을 보증하지 않습니다.

## 2026.10.30 모바일·일조 화면 수정

- 휴대폰 기본 화면은 풍경을 중심으로 보여 줍니다. 거리·미니맵은 하단 '주변 정보'에서 엽니다.
- 하단 '일조'에서 봄·여름·가을·겨울과 시각을 선택하면 태양 방향·그림자·현재 직사광 상태가 함께 바뀝니다.
- 노란 시간띠는 창면과 실내 1m 눈높이 한 점의 직사광 시간입니다. 바닥 그림은 선택 창 하나 앞 4m×4m 가정 영역이며 실제 거실 평면이나 조도가 아닙니다.
- '하루 재생' 또는 '직사광 시각' 버튼으로 변화하는 시각을 비교할 수 있습니다. 창 좌표 오차가 큰 시점은 수치·바닥 그림을 보류합니다.
- 이미 게시했다면 아래 파일들을 같은 저장소 위치에 덮어씁니다. 웹페이지를 새로 고친 뒤 하단 네 버튼이 보이면 이번 화면입니다.
- 공개본 파일 무결성과 동작·기하 검사를 수행했습니다. 실제 아이폰 실기기 화면 검증은 아직 하지 않았습니다.

## GitHub에 직접 올리기

1. 새 저장소를 만듭니다. 무료 계정으로 GitHub Pages를 사용할 경우 Public 저장소를 선택합니다.
2. **이 폴더 안의 내용 전체**를 저장소 맨 위에 업로드합니다. ZIP 파일이나 `github-pages` 폴더 자체를 한 단계 아래에 올리지 않습니다.
3. 저장소 첫 화면에 `index.html`, `data.js`, `app.js`, `assets/`, `vendor/`가 보여야 합니다.
4. `Settings → Pages → Build and deployment → Source: Deploy from a branch`를 선택합니다.
5. `Branch: main`, 폴더 `/(root)`를 선택하고 Save를 누릅니다.
6. Pages 화면에 게시 완료 주소가 표시되면 그 주소를 아이폰 Safari에서 엽니다. 저장소 주소나 raw 파일 주소는 웹사이트 주소가 아닙니다.

커스텀 빌드 명령은 필요하지 않습니다. 자산·링크는 상대경로이므로 저장소 이름이 달라도 작동합니다.
이 폴더의 `index.html`만 따로 보내면 사진과 실행 파일이 빠집니다.

## 자료와 계산의 범위

- 개인의 주택 보유·당첨·미계약 상태를 연결한 메모를 제외한 공유본입니다. 109동 3301호는 일반 비교 예시로만 표시합니다.
- 세금 계산의 주택 수·대출 조건은 계산 예시이며 이용자의 실제 상태를 나타내지 않습니다.
- 공개 자료 확인일과 가정은 화면의 자료·보고서에 표시합니다. 실시간 재고 조회는 하지 않습니다.
- 원본 사진과 지도·평면도 출처 표시는 유지합니다. 제3자 자료의 권리를 별도로 부여하는 저장소가 아닙니다.
- Three.js의 라이선스 표기는 vendor 파일에 유지합니다. 지도 자료는 화면의 OpenStreetMap 등 원출처와 이용 조건을 확인하세요.
